# HiddenCMS 0.3.3

Release corrective de HiddenCMS Core.

## Correction

- Correction du plantage de la modale de mise à jour lorsque les logs sont activés.
- Le logger utilise désormais l'horodatage natif de PHP et ne dépend plus du chargeur interne pendant le remplacement des fichiers du Core.

## Compatibilité et migrations

- PHP : `>= 8.1`.
- Schéma de base de données : `0.3.1`.
- Aucune nouvelle migration SQL pour cette release.
- Mise à jour directe possible depuis `0.3.2`.

## Après la mise à jour

- Vérifier que la modale de mise à jour se termine sans erreur lorsque les logs sont activés.
- Vérifier que le mode maintenance a été désactivé automatiquement.
