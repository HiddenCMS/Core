# HiddenCMS 0.5.0

Cette version introduit les pages hierarchiques et consolide plusieurs elements
de formulaire et de navigation du core.

## Pages hierarchiques

- Une page peut desormais avoir une page parente.
- Les URLs reprennent toute la hierarchie, par exemple
  `/parent/enfant/petit-enfant`.
- Le selecteur de parent empeche les cycles et exclut la page en cours ainsi
  que ses descendants.
- L'unicite du slug est verifiee parmi les pages partageant le meme parent.
- La suppression d'une page possedant des enfants est bloquee afin d'eviter
  les liens orphelins.
- La recherche, les menus, les audits de confidentialite et les helpers de
  sortie utilisent maintenant le chemin complet des pages.

## Navigation

- Le fil d'Ariane affiche les pages parentes dans leur ordre hierarchique.
- Le titre du site est maintenant un lien vers l'accueil.
- L'entree generique `Pages` n'est plus inseree entre l'accueil et une page.

## Formulaires

- Les champs numeriques acceptent la virgule comme separateur decimal tout en
  conservant une valeur normalisee pour la validation.

## Migration

- Ajout de `parent_id` a la table des pages.
- L'index d'unicite des slugs porte desormais sur `parent_id` et `name`.

Version du schema : `0.3.7`. Mise a jour directe possible depuis `0.4.1`.
