# HiddenCMS 0.3.4

Release corrective de HiddenCMS Core.

## Correction

- Empêche le retour de l'installateur après une mise à jour du Core.
- Recrée automatiquement le marqueur `install/installed.txt` lorsque l'archive restaure le répertoire `install`.
- Protège le marqueur pendant les mises à jour et les retours arrière futurs.
- Ignore l'installateur tant qu'une mise à jour du Core est en cours.

## Compatibilité et migrations

- PHP : `>= 8.1`.
- Schéma de base de données : `0.3.1` (inchangé).
- La migration de maintenance `0.3.4` sécurise le répertoire d'installation restauré sans modifier la base.
- Mise à jour directe possible depuis `0.3.3`.

## Après la mise à jour

- Vérifier que le site revient sur l'administration et non sur l'installateur.
- Vérifier la présence de `install/installed.txt` si le répertoire `install` a été restauré.
- Le répertoire `install` peut ensuite être supprimé manuellement sans risque ; les prochaines mises à jour recréeront le marqueur si nécessaire.
