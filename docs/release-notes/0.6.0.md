## Nouveautes

- Altitude devient le theme front installe et active par defaut.
- Ajout des widgets Image, Hero et Image avec texte pour composer les pages.
- Nouvelles pages utilisateur pour la connexion, l'inscription, la reinitialisation du mot de passe et le profil.
- L'editeur TinyMCE remplace WysiBB pour le contenu libre et la signature utilisateur.
- Detection modernisee des navigateurs et systemes d'exploitation dans les sessions.

## Corrections

- Correction de l'isolation des dimensions et des fonds de colonnes dans le Live Editor.
- Correction du selecteur de couleurs dans l'administration de l'apparence.
- Les vues front des modules privilegient maintenant les overrides du theme actif.
- Suppression des appels externes de geolocalisation et de detection du navigateur.

## Compatibilite et migrations

- PHP : 8.1 ou version superieure.
- Schema de base de donnees : 0.3.8, migration automatique incluse.
- Altitude : 0.1.x, installe par Composer avec le Core.
- News : 0.1.1 compatible avec cette version.

## Apres la mise a jour

- Synchroniser les addons si Altitude n'apparait pas immediatement dans l'administration.
- Les installations existantes conservent leur theme actif ; Altitude est le choix par defaut des nouvelles installations.
