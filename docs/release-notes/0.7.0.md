## Nouveautes

- Nouvelle mediatheque reutilisable fournie par le module Fichiers.
- Selection et apercu des images directement dans les widgets Image, Hero et Image avec texte.
- Televersement de fichiers depuis la modale de selection sans quitter le Live Editor.
- Integration de la mediatheque dans TinyMCE pour inserer une image ou un lien vers un fichier.
- Le Live Editor accepte maintenant des options d'apparence independantes du style principal d'un widget.

## Corrections

- Conservation fiable des classes d'apparence lors du changement de style d'un widget.
- Les modales de selection de fichiers peuvent s'ouvrir au-dessus de la configuration d'un widget sans la fermer.

## Compatibilite et migrations

- PHP : 8.1 ou version superieure.
- Schema de base de donnees : 0.3.8, aucune nouvelle migration.
- Altitude : 0.2.x.
- News : 0.1.2 recommande pour la compatibilite avec Core 0.7.

## Apres la mise a jour

- Mettre a jour les paquets HiddenCMS proposes par Composer avant ou pendant la mise a jour du core.
- Aucun reglage manuel ni changement de base de donnees n'est requis.
