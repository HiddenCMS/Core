# HiddenCMS 0.7.3

## Ameliorations

- TinyMCE enrichi : polices, couleurs, tableaux, recherche, code, apercu et plein ecran.
- Insertion de lecteurs PDF depuis la mediatheque, avec selection et televersement filtres.
- Conservation des styles et images autorises dans les contenus admin ; filtrage strict maintenu pour les profils.
- Option Contenu seul pour le widget image, sans carte ni en-tete, avec conservation des helpers de mise en page.
- Page de maintenance plus lisible sur ordinateur et mobile, sans collision avec les couleurs du theme.
- Correction du doublon de bouton cookies et rafraichissement des fichiers du gestionnaire de consentement.

## Compatibilite

- PHP >= 8.1. Aucune nouvelle migration SQL ; schema 0.7.1 conserve.
- Recommande avec Altitude 0.3.1 pour les corrections de navigation et du bouton cookies flottant.
- Les extensions premium TinyMCE ne sont pas incluses.
