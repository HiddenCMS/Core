# HiddenCMS 0.7.6

## Editeur

- Les fenetres Image, Video et Lien de TinyMCE n'affichent plus le selecteur de mediatheque. Elles permettent toujours de saisir une URL externe.
- L'onglet de televersement de la fenetre Image est retire.
- Les boutons dedies Mediatheque et Lecteur PDF restent disponibles pour les fichiers du site.

## Compatibilite et migrations

- PHP >=8.1 conserve. Aucune modification des contraintes des addons.
- Aucune migration SQL ; schema 0.7.1 conserve.
- Aucune action manuelle apres la mise a jour.

Validation : syntaxe JavaScript et controle de la configuration TinyMCE. Installation neuve, mise a jour complete et verification visuelle des dialogues non retestees pour cette release.
